# 给 ChatGPT 的交接说明

你现在要帮我继续打磨一条中文视频文案。

## 主题

AI 多模型多 agent 运作是什么？

## 这条视频当前已经确定的主线

不要把它讲成抽象的“AI 很厉害”。

要围绕这条线展开：

- 很多人不是不会用 Codex
- 而是还在用聊天思维解决本来应该调度的工作
- 多模型是角色分工
- 多 agent 是任务装配
- 老板思维是目标、约束、验收、检查点
- 真正高效的协作，是把思考外化成具体产物和可审查流程

## 目标受众

普通打工人、内容创作者、知识工作者。

他们不一定是技术人，但每天都在处理：

- 信息很多
- 步骤很碎
- 判断不多
- 特别容易返工

## 已经固定的两个案例

### 案例一

这条视频本身如何被一个多 agent 团队生产出来。

包括：

- 资料研究
- 主脚本
- 分镜
- 审校
- 工程接入

### 案例二

把群聊截图整理成礼品统计和采购预算表。

这是一个更像办公室真实脏活的例子，要用它讲清楚：

- 重复性工作
- skill
- 自动化任务

三者不是一个层级。

## 这轮你要做的事

请基于我已有的文案，继续往“更像 B 站口播、更像真人在说”这个方向修。

重点不是补知识点。
重点是：

1. 更有钩子
2. 更有代入感
3. 更像真实说话
4. 更少空话
5. 更少 AI 味

## 你要避免的方向

不要写成：

- 企业培训腔
- 空泛方法论
- 大词堆砌
- 未来趋势宣讲
- “认知升级”“高效协同”“范式跃迁”“全面赋能”这种没有具体动作支撑的表达

## 口吻要求

要像一个长期在试工具、拆流程、看产品的人在讲。

风格关键词：

- 冷静，但不冷淡
- 有判断，但不端着
- 说人话
- 有真实工作压力感
- 不卖弄
- 不喊口号

## 你输出时最该优先优化的地方

1. 开头前 20 秒
2. 两个案例的画面感
3. “老板思维”这部分怎么讲得更自然
4. 结尾怎么收得更像真人建议，而不是总结陈词

## 输出形式

请给我：

1. 一版重新润色后的完整发布文案
2. 一版更适合 B 站口播的短句化版本
3. 额外指出 5 处你觉得原来最容易掉传播力的地方，并说明为什么
